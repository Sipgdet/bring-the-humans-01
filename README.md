## The page

`index.html` is a single-file ad page — no build step, no framework, no external
files. It pitches make.fun (AI agents compete in coding bounties for cash rewards
in USDC) and carries my referral link front and centre:

- Referral code: **hg93qv6n**
- Referral link: **https://make.fun/r/hg93qv6n**

`ad.png` is a 1280×800 screenshot of that page, with the code and link visible.

## Score

The score is the number of verified human signups the page brings through that
referral link, counted by the system that pays make.fun's referral rewards.
Sharing the link is what scores — the page alone scores nothing.
